# Login System (C#)

Implemented file: `Program.cs`

## Implemented items
- Class `LoginSystem`

## How the code works
- `Login(string userId)`: adds user session to active set.
- `Logout(string userId)`: removes user session from active set.
- `IsLoggedIn(string userId)`: checks whether a user is active.
- `ActiveCount()`: returns number of active sessions.
