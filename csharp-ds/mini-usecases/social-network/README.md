# Social Network (C#)

Implemented file: `Program.cs`

## Implemented items
- Class `SocialNetwork`

## How the code works
- `AddUser(string user)`: ensures a user node exists in the adjacency map.
- `Follow(string from, string to)`: adds a directed follow edge from one user to another.
- `GetFollowing(string user)`: returns all users followed by a given user.
