# Playlist Manager (C#)

Implemented file: `Program.cs`

## Implemented items
- Class `PlaylistManager`

## How the code works
- `Add(string song)`: adds an item into internal storage.
- `Remove(string song)`: removes and returns one item based on class behavior.
- `Move(int from, int to)`: reorders a stored item from one index to another when indices are valid.
- `List()`: returns current stored items.
