# Data Structures Playground (TypeScript + C#)

A step-by-step project to master data structures with both **TypeScript** and **C#**, then apply them to real-world mini projects and interview preparation.

## Learning Path

### Phase 1 - Fundamentals (Core DS)
Focus: understanding + implementation.

For each data structure folder:
- README.md: what it is, when to use it, complexity
- <name>.ts: TypeScript implementation
- <name>.cs: C# implementation

Goal:
- Build basic operations
- Understand trade-offs
- Compare TS and C# approaches

### Phase 2 - Mini Use Cases (Real World)
Focus: practical application.

For each mini project:
- README.md: scenario and requirements
- solution.ts: TypeScript solution
- Program.cs: C# solution
- 	ests.ts: basic test scenarios

Goal:
- Apply DS to realistic features
- Keep logic clean and modular
- Practice test-driven thinking

### Phase 3 - Interview Prep
Focus: concise, high-value revision.

Each topic file includes:
- What it is
- When to use it
- One coding-style prompt/snippet
- Time complexity notes

Goal:
- Fast recall for interviews
- Practical, short answers

### Phase 4 - Patterns
Focus: problem-solving maturity.

Patterns covered:
- Sliding Window
- Two Pointers
- Recursion
- BFS/DFS
- Backtracking

Goal:
- Recognize common problem patterns
- Improve interview speed and confidence
