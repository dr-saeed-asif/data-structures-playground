# Arrays — mini use cases

These examples mainly work with **lists / arrays** (sorting, filtering, scanning, reordering).

| Folder | Focus |
|--------|--------|
| `trending-products/` | Count and rank items from a list of events |
| `search-engine/` | Filter a list of strings by query |
| `duplicate-remover/` | Remove duplicates while keeping first-seen order |
| `autocomplete/` | Prefix search over a word list |
| `sliding-window/` | Fixed-size window over a number array |
| `priority-feed/` | Sort items by score and take top N |
| `playlist-manager/` | Add, remove, and reorder items in a list |
| `task-scheduler/` | Pick next task from a list by priority |

Other mini use cases (stacks, sets, graphs) stay in `mini-usecases/` at the parent level.
